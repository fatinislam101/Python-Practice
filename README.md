# Python Practice

Practice exercises from Week 1 of my 12-week Data Science and Machine Learning learning plan.

## What's inside

Short Python programs solved on my own, covering:

- Lists, sets and dictionaries
- Functions, `return` and default values
- List comprehensions
- Strings and slicing
- Reading files and handling errors with `try/except`
- Reading error messages and debugging

## Example problems

- Count how often each word or letter appears in text
- Check whether a sentence is a palindrome
- Build a running total from a list of numbers
- Safely look up a key in a dictionary
- Fix broken code and handle edge cases such as empty input

## Goal

Build a solid Python base before moving on to NumPy, pandas, statistics and machine learning, and to finish with three portfolio projects.
